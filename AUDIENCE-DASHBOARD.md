# PRAYZVIBES audience dashboard

Review this once a month. The purpose is to learn which doorway people actually use, not to chase every number.

| Signal | Website event or source | What it answers |
|---|---|---|
| Release intent | `listen_click` | Which release or player link earns a click? |
| Direct preview | `preview_play` | Do visitors start the Mountain Day short from the release player? |
| Live interest | `live_click` and Salzburg `video_play` | Does the real street moment lead to booking or more live viewing? |
| Shop interest | `shop_click` | Is the interest in music, physical editions or merch? |
| Direct support | `support_click` plus `support_source` | Which support position works without pressure? |
| Wider universe | `playlist_click` | Which PRAYZ World or remix route invites exploration? |
| Professional interest | `epk_click` | Are press and booking visitors reaching the EPK? |
| Owned audience | `newsletter_submit` | Are visitors choosing to stay in touch? |
| Language | `page_language` and `language_change` | Which language path is actually used? |
